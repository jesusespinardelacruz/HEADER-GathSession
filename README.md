# Gathsession —  Header & Landing Page



### Frontend Development 

Proyecto de maquetación web desarrollado como parte de mi formación en **Desarrollo Full Stack en Conquer Blocks**.

El objetivo es reproducir una interfaz moderna a partir de un diseño de referencia, prestando especial atención a la estructura HTML, la organización de estilos con Sass y la distribución de elementos mediante Flexbox.

---

## Sobre el proyecto

El proyecto se desarrolla utilizando HTML y Sass, sin necesidad de frameworks CSS ni Js.

## Características

- Navegación superior con logotipo y enlaces alineados mediante Flexbox.
- Indicador visual para el enlace de navegación activo.
- Efectos hover y transiciones suaves.
- Botones y enlaces personalizados.
- Uso de variables Sass para mantener una paleta visual coherente.
- Organización modular de hojas de estilos SCSS.
- Integración de fuentes tipográficas.
- Distribución de elementos y composición de la interfaz con Flexbox.


## Instalación y ejecución

**1. Clonar el repositorio**

```bash
git clone URL_DEL_REPOSITORIO
```

**2. Acceder al directorio**

```bash
cd header-gathsession
```

**3. Instalar Sass**

```bash
npm install -D sass
```

**4. Compilar los archivos SCSS**

```bash
npx sass sass/style.scss css/style.css
```

Para activar la compilación automática durante el desarrollo:

```bash
npx sass --watch sass/style.scss:css/style.css
```

**5. Abrir el proyecto**

Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.
